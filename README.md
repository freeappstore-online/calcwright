# Calcwright

**Coming soon — pro calculators for money and the trade: time value of money, loans, NPV/IRR
and conduit bending. Offline and private.** A free app on [FreeAppStore](https://freeappstore.online), live at
https://calcwright.freeappstore.online.

Right now this is a shell: it lists the planned features, but none of them work yet. Progress is
tracked in
[freeappstore-online/platform#248](https://github.com/freeappstore-online/platform/issues/238).

## Develop

```bash
pnpm install
pnpm dev      # local dev server
pnpm build    # production build in web/dist
fas check     # FreeAppStore compliance checks
```

Pushes to `main` auto-deploy via GitHub Actions.
